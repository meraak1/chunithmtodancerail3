# UMIGURI To DanceRail3

This is a converter that will convert UMIGURI (Chunithm) beatmaps to DanceRail3 charts.
Only UMIGURI beatmaps (.ugc) are supported.

To find UMIGURI beatmaps, check pgko.dev and the UMIGURI Discord 
server (https://discord.com/invite/j6mEU2hQDZ)

This converter focuses on making the converted file fun to play in DR3, 
rather than going for 1:1 accuracy.
It outputs zip files that are ready to be imported into my DR3 Custom 
app (https://www.youtube.com/watch?v=JSuXkqWYa4o), with no extra work required.


# How to use

Use the converter at https://meraak1.github.io/chunithmtodancerail3/

Alternatively, download the ugc2dr3.py script and run it:

```
py ugc2dr3.py song1.zip song2.zip
```
